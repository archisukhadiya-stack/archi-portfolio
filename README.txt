# Archi Sukhadiya — Portfolio

A simple responsive portfolio built with HTML and CSS.

## Preview locally
Double-click `index.html` to open it in your browser.

## Before submitting
- Confirm the education/college wording is correct.
- Add phone number only if you want it public.
- Add GitHub/LinkedIn links after you have verified them.
- TaskFlow is currently described as a local project because public hosting is not complete.
- To publish this portfolio, upload the files to a GitHub repository and enable GitHub Pages, or use a static hosting provider.
